# DBMS Experiments - SQL Practicals

Complete implementation of 10 DBMS experiments covering database design, SQL queries, joins, views, stored procedures, normalization, transactions, and query optimization.

## Experiments Overview

| Exp | Topic | CO |
|-----|-------|-----|
| 1 | ER Diagram Design (E-commerce Platform) | CO1 |
| 2 | Relational Schema & MySQL CREATE TABLE Statements | CO1 |
| 3 | Employee-Department-Project Schema with Queries | CO2 |
| 4 | JOIN Operations & Subqueries with EXPLAIN | CO2 |
| 5 | Views & Recursive CTEs | CO3 |
| 6 | Stored Procedures & Triggers | CO3 |
| 7 | Normalization (1NF, 2NF, 3NF, BCNF) | CO4 |
| 8 | Transactions, ACID, Isolation Levels | CO4 |
| 9 | Railway Booking System (5000+ records, Indexing) | CO5 |
| 10 | Query Optimization & Performance Analysis | CO5 |

## Prerequisites

- MySQL Server 5.7+
- MySQL Workbench
- Basic SQL knowledge

## Setup Instructions

1. Clone repository
```bash
   git clone https://github.com/krishgupta0921/DBMS_LAB_FILE_3134.git
   cd DBMS_LAB_FILE_3134
```

2. Open MySQL Workbench and create database
```sql
   CREATE DATABASE DBMS_LABFILE_3134;
   USE DBMS_LABFILE_3134;
```

3. Execute experiments in order (Exp 1 → Exp 10)

4. Run queries from corresponding `.sql` files
